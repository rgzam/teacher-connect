# User stories (MVP)

These are the stories we will implement after the foundation is running.

## Teacher

1. As a teacher, I can log in so only I can see my class contacts.
2. As a teacher, I can see today's appointments and contact tasks on one dashboard.
3. As a teacher, I can add a student and their guardian with fictional or approved data.
4. As a teacher, I can create a contact task with a reason, priority, and due date.
5. As a teacher, I can record a contact attempt and see that history later.
6. As a teacher, I can set a follow-up date so overdue calls do not get lost.
7. As a teacher, I can set weekly availability and appointment types.
8. As a teacher, I can connect Google Calendar so busy times are blocked.

## Parent

1. As a parent, I can open a teacher booking link without creating an account.
2. As a parent, I can pick an appointment type, date, and open time slot.
3. As a parent, I can enter my name and reason, then confirm the booking.
4. As a parent, I only see open slots, never the teacher's personal calendar details.

## System

1. If two parents book the same slot at the same time, only one booking is saved.
2. Public booking endpoints are rate limited.
3. Demo and portfolio data stay fictional.
